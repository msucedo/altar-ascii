# Política de seguridad

*English summary: only the latest release is supported. Please report vulnerabilities privately through GitHub's "Report a vulnerability" button in the Security tab, not in a public issue.*

## Versiones con soporte

Solo la última versión publicada en [Releases](https://github.com/msucedo/altar-ascii/releases) recibe correcciones.

## Cómo reportar un problema

Si encuentras un problema de seguridad, repórtalo en privado desde la pestaña **Security → Report a vulnerability** de este repositorio. Por favor no abras un issue público, para que nadie pueda aprovecharlo antes de que esté corregido.

Incluye, si puedes, la versión de Altar y de macOS, los pasos para reproducirlo y qué pasa.

## Qué esperar

Es un proyecto personal, así que la respuesta puede tardar unos días. Cuando el problema esté confirmado, sale una versión nueva con la corrección y se menciona en las notas del Release.

## Alcance

Altar no se conecta a internet ni recopila datos. Solo guarda su configuración (niveles, ofrendas y nombres) en las preferencias de macOS de tu usuario.

Los DMG de Releases van firmados con Developer ID y notarizados por Apple. Si macOS dice que no puede verificar una copia de Altar, no la abras: bájala de nuevo de Releases.
